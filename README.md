# פרויקט מסכם - רשתות תקשורת מחשבים 📡

**מוגש ע"י:** אביטל יוחננוב, נאור אנידג'ר

## 📖 אודות הפרויקט
פרויקט זה מדגים יישום מעשי של עקרונות התקשורת שנלמדו בקורס. הפרויקט מחולק לשני חלקים עיקריים:
1.  **חלק 1 (Packet Analysis):** סימולציה של אריזת נתונים (Encapsulation), שליחתם ברשת ולכידתם.
2.  **חלק 2 (Chat Application):** פיתוח מערכת צ'אט מלאה (לקוח-שרת) מבוססת TCP Sockets.

---

## 📦 חלק 1: סימולציית תעבורה וניתוח מנות
בחלק זה יצרנו הודעות ברמת האפליקציה (HTTP), ביצענו להן אריזה ידנית (Encapsulation) לפקטות TCP/IP באמצעות קוד Python, ושידרנו אותן ברשת הפנימית כדי ללכוד ולנתח אותן ב-Wireshark.

### 📂 קבצי חלק 1
* `groupAvitalNaor_http_input.csv` - קובץ הקלט המכיל את הודעות ה-HTTP שיצרנו.
* `project_notebook.ipynb` - מחברת הקוד (Jupyter) שמבצעת את תהליך האריזה, הוספת הכותרות (Headers) והשליחה.
* `capture.pcap` - קובץ הלכידה מ-Wireshark שמוכיח שההודעות עברו בצורה תקינה.
* `Part1_Report.pdf` - הדוח המסכם עם הסברים וצילומי מסך.

### ⚙️ איך להריץ את חלק 1?
1.  פתחו את המחברת `project_notebook.ipynb`.
2.  וודאו שקובץ ה-CSV נמצא באותה תיקייה.
3.  הריצו את התאים לפי הסדר לביצוע הסימולציה.
4.  ניתן לפתוח את `capture.pcap` ב-Wireshark כדי לראות את התוצאות (מומלץ לסנן לפי פורט TCP).

---

## 💬 חלק 2: מערכת צ'אט (TCP Client-Server)
בחלק זה פיתחנו מערכת צ'אט המאפשרת למספר משתמשים להתחבר לשרת מרכזי, להתכתב ביניהם ולשלוח הודעות פרטיות.
המערכת תומכת ב-Multi-Threading כדי לטפל במספר לקוחות במקביל ללא תקיעות.

### ✨ פיצ'רים מרכזיים
* **שרת מרכזי:** מנהל את רשימת המחוברים ומנתב הודעות.
* **תמיכה בריבוי משתמשים:** שימוש ב-`threading` כדי לאפשר שיחות במקביל.
* **פרוטוקול טקסטואלי:** פקודות פשוטות לניהול השיחה (CONNECT, MSG).
* **ממשק גרפי:** בנוסף לטרמינל הרגיל, פיתחנו ממשק GUI נוח וידידותי למשתמש.

### 📂 קבצי חלק 2
* `server.py` - קוד השרת. מאזין לחיבורים ומנהל את התקשורת.
* `client.py` - קוד לקוח בסיסי (CLI).
* `gui_client.py` - קוד לקוח מתקדם הכולל ממשק גרפי (GUI).
* `Part2_report.pdf` - הדוח המסכם עם הסברים וצילומי מסך.

### 🚀 הוראות הרצה (חלק 2)

**שלב 1: הפעלת השרת**
פתחו טרמינל והריצו את הפקודה:

    python server.py

**שלב 2: הפעלת הלקוחות**
פתחו טרמינל חדש (עבור כל משתמש) והריצו את הלקוח:

    python client.py


או לחילופין:

    python gui_client.py

*(ייפתח חלון בו תתבקשו להזין שם משתמש ולהתחבר)

### 📡 פקודות הפרוטוקול
* `CONNECT <username>` - יצירת חיבור לשיחה פרטית מול משתמש אחר.
* `MSG <text>` - שליחת הודעה למשתמש שאיתו אתם בשיחה.
* `DISCONNECT` - סיום השיחה הנוכחית (ניתוק מהמשתמש השני).
