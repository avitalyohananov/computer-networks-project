#  פרויקט מסכם: רשתות תקשורת מחשבים

**מגישים:** אביטל יוחננוב, נאור אנידג'ר

##  תקציר הפרוייקט
בפרויקט זה יישמנו את עקרונות התקשורת שנלמדו בקורס. העבודה התחלקה לשני שלבים עיקריים:
1.  **שלב א' (Packet Analysis):** ביצוע Encapsulation ידני, תעבורת רשת וניתוח מנות.
2.  **שלב ב' (Chat Application):** פיתוח אפליקציית צ'אט (Client-Server) על גבי פרוטוקול TCP.

---

## חלק 1: סימולציית תעבורה וניתוח מנות
בחלק זה יצרנו קובץ נתונים (HTTP), ביצענו עטיפה (Encapsulation) ידנית לפרוטוקול TCP/IP על ידי קוד Python, ושידרנו את הפקטות בממשק הלוקאלי (Loopback) לצורך לכידה ב-Wireshark.

###  קבצי חלק 1
* `groupAvitalNaor_http_input.csv` - קובץ הנתונים (הודעות HTTP).
* `project_notebook.ipynb` - מחברת Jupyter המבצעת את תהליך האריזה והשליחה.
* `capture.pcap` - קובץ הלכידה המציג את התעבורה שעברה בפועל.
* `Part1_Report.pdf` - דוח מסכם עם הסברים וצילומי מסך.

###  הוראות הרצה (חלק 1)
1. יש לפתוח את המחברת `project_notebook.ipynb`.
2. לוודא שקובץ ה-CSV נמצא באותה תיקייה.
3. להריץ את התאים (Cells) לפי הסדר.
4. לפתוח את `capture.pcap` ב-Wireshark לצפייה בתוצאות.

---

## חלק 2: מערכת צ'אט (TCP Sockets)
בחלק זה פיתחנו מערכת צ'אט המאפשרת למספר משתמשים להתחבר לשרת מרכזי, לנהל רשימת משתמשים מחוברים ולשלוח הודעות פרטיות.
המערכת משתמשת ב-**Multi-Threading** כדי לאפשר תקשורת במקביל ללא חסימות.

### תכונות המערכת
* **ניהול מרוכז:** שרת המנהל את כלל החיבורים וההודעות.
* **תמיכה בריבוי משתמשים:** שימוש ב-Threads לטיפול במספר לקוחות במקביל.
* **פרוטוקול מותאם:** שימוש בפקודות טקסטואליות (CONNECT, MSG, DISCONNECT).
* **ממשק כפול:** תמיכה בממשק שורת פקודה (CLI) ובממשק גרפי (GUI).

### קבצי חלק 2
* `server.py` - קוד השרת.
* `client.py` - קוד הלקוח (CLI).
* `gui_client.py` - קוד הלקוח (GUI).
* `Part2_report.pdf` - דוח מסכם עם הסברים וצילומי מסך.

###  מדריך התקנה והרצה

**1. הפעלת השרת:**

    python server.py

**2. הפעלת לקוח (יש לבחור אחת מהאפשרויות):**

*אפשרות א' - ממשק גרפי (מומלץ):*

    python gui_client.py

*אפשרות ב' - טרמינל:*

    python client.py

###  פקודות הפרוטוקול

| פקודה | תיאור |
| :--- | :--- |
| `CONNECT <username>` | בקשת חיבור לשיחה עם משתמש אחר |
| `MSG <text>` | שליחת תוכן הודעה לנמען |
| `DISCONNECT` | סיום השיחה הנוכחית |
